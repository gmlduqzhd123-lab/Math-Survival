# Jua

Source: https://github.com/google/fonts/tree/main/ofl/jua

Copyright 2018 The Jua Project Authors. See `OFL-Jua.txt` for the SIL Open Font License 1.1.

`Jua-Regular.woff2` is a format conversion of the upstream `Jua-Regular.ttf`, with the original glyphs and font naming retained. The complete Korean and Latin font is served locally with the game; no Google Fonts request is needed at runtime.

# Pretendard Variable

Version 1.3.9, unmodified upstream variable WOFF2. Source: https://github.com/orioncactus/pretendard/tree/v1.3.9/packages/pretendard/dist/web/variable/woff2
Copyright 2021 Kil Hyung-jin; SIL Open Font License 1.1 in `OFL-Pretendard.txt`. Served locally and cached for offline play. Used for interface and canvas labels; Jua is reserved for the large home title.

# Do Hyeon

Source: https://github.com/google/fonts/tree/main/ofl/dohyeon

Copyright 2018 The Do Hyeon Project Authors. See `OFL-Do-Hyeon.txt` for the SIL Open Font License 1.1 (no Reserved Font Name).

`DoHyeon-Title.woff2` is a subset holding only the home title and grade-card glyphs (`매쓰 서바이벌`, digits, `.`, `학년`), about 3 KB. Add any new characters to the subset before using this font for other text; missing glyphs fall back to Jua.
