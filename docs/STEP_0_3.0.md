## 보존과 연결

기존 math-survival-2.learning.v2/schemaVersion 2와 storage.js/mastery.js의 기존 의미를 유지한다. 새 모드는 기존 학습 모드(survival/explore/boss)에 매핑하고 gameMode 추가 필드로 구분하여 과거 백업이 격리되지 않게 한다. 영구 성장은 math-survival-3.progress.v1에 저장한다. 기존 키의 자동 초기화·전체 삭제·강제 이관을 하지 않는다. 새 저장소가 손상되면 원문을 보존하고 저장 실패를 표시한다.

엔진의 고정 60Hz 시계·Canvas 논리 좌표·3백만 픽셀 예산·기존 시스템을 유지하며 작은 연결 훅을 추가한다. 새 모듈은 기존 runtime 및 기존 공격/피해/레벨업/문항/종료 경로를 활용한다. 화면 밖 적은 낮은 빈도로 AI 처리하고 원거리 투사체·이펙트·경험치 보석 수를 제한한다.

## 순서와 통과 기준

1. STEP 1: 공간 인덱스/풀 → 10 AI/웨이브 → 기존 이동·투사체 충돌 연결. 인접 검색, AI 상태 전이, 상한·경험치 보존, 브라우저 전투 검증.
2. STEP 2: 무기/패시브/진화/합체 데이터 → 공격/렌더링 → 성장 카드/보물상자. 모든 정의의 실제 공격과 진화 조건 검증.
3. STEP 3: 기존 학습 기록에 수학 에너지·멱등 보상·팝업/시간 제어·보스 보호막 연결. 기존 수학·숙련도·백업 회귀 검증.
4. STEP 4: 캐릭터/펫/월드/보스/이벤트. 각 콘텐츠의 선택·스킬·피해·보상·전환 검증.
5. STEP 5: 영구 성장/도감/업적/모드/HUD/음량. 손상·quota·중복 지급·해금·날짜 시드 검증.
6. STEP 6: URL 과제·로컬 결과 합산·개념 통계. 설정 유효성·파일 제한·중복 세션·개인정보 최소화 검증.
7. STEP 7: 전체 회귀/장시간/반응형/정적 빌드 경로. 실제 기기 및 오디오 청취는 자동 브라우저 검사와 구분한다.

각 단계는 로컬 체크포인트를 만든다. 기능 수만 채운 선언·빈 버튼은 완료로 표시하지 않는다. 최종 배포는 승인 대기 상태로 남긴다.
