# STEP 5 — 영구 성장·게임 모드·UI

학습 저장 키와 분리한 `math-survival-3.progress.v1`에 골드, 강화 5종, 해금, 33개 업적, 도감, 게임 기록을 저장한다. 손상 원문은 덮어쓰지 않는다. 백업 복원은 미리 보기 후 적용한다.

8/15/20/30분 생존, 20웨이브 성문 방어, 3문항마다 방 보상을 받는 수학 던전, 무한 보스 도전, 서울 날짜 기반 8분 도전을 기존 3개 모드 위에 연결했다. 오늘의 도전은 날짜에 따라 월드와 일부 생성 패턴이 결정되며 모든 물리 결과가 동일한 리플레이를 의미하지 않는다.

음량 조절은 실제 WebAudio 게인에 연결했다. HUD는 200ms마다 변경된 텍스트만 갱신한다.

검증: 단위 80/80, 기존 브라우저 회귀 30개, 콘텐츠 브라우저, 성장·해금·신규 5모드·중복 정산 브라우저 검사 통과. 옵션의 잠금은 네이티브 `option.disabled` 속성으로 검증한다. 실제 스마트폰 성능과 음원 청취는 아직 검증하지 않았다.
