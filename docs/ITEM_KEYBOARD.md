# 아이템 키보드 선택 · 2026-10-11

- 레벨업 화면은 첫 카드에 자동 포커스를 둔다. 방향키 좌우는 순서대로 이동하며 위아래는 표시된 행의 가까운 카드로 이동한다. 해당 방향에 카드가 없으면 이전/다음 카드로 순환한다. 선택지는 파란 테두리로 표시한다.
- Enter는 기존 클릭 핸들러를 호출한다. 마우스·터치 보상 코드를 재사용하며 새 보상 경로를 만들지 않는다. 연속 레벨업에서 Enter를 길게 눌러도 다음 보상까지 소비하지 않는다.
- 상인 화면도 같은 조작을 지원하고 구매 불가능한 버튼을 건너뛴다. ‘다음에 올게요’도 키보드로 선택할 수 있다.
- 카드가 열릴 때 이동 키·조이스틱·대시 입력을 초기화한다. 카드가 닫히면 포커스를 해제하며 이미 닫힌 카드의 보상은 다시 적용하지 않는다. 열린 일시정지 메뉴와 입력 필드에서는 아이템 탐색을 가로채지 않는다.

검증: 단위 테스트 91개, Edge/Chromium와 WebKit의 PC 1440×900 및 390×844 화면 4개에서 첫 포커스, 네 방향, 순환, 전투 시간 정지, 연속 레벨업, Enter 반복, 닫힌 카드 재입력, 마우스 클릭, 비활성 상인 상품 건너뛰기, 실제 골드 차감·에너지 지급을 확인했다. WebKit에서 숨겨진 카드에 포커스가 남아 Enter로 다시 선택될 수 있는 문제를 발견해 포커스 해제와 보상 상태 가드로 수정한 뒤 네 조합을 재검증했다. 정적 빌드와 오프라인 실행도 통과했다.

원본 파일과 학습·성장 저장 코드는 변경하지 않는다. Supabase 작업은 포함하지 않는다.
