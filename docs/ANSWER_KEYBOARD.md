# 수학 답안 키보드 선택 · 2026-10-11

- 기존 아이템 방향키 탐색을 재사용하여 수학 탐험, 문제 팝업, 전투 답안 버튼을 지원한다. 첫 답안에 자동 포커스를 두고 현재 선택은 파란 테두리로 표시한다.
- 방향키는 표시된 버튼 사이를 이동하고 Enter는 기존 클릭·정답 판정을 호출한다. 팝업에서 힌트 버튼을 Tab으로 선택한 뒤 Enter를 누르는 기존 동작도 유지한다.
- 탐험과 팝업은 응답 후 해설의 계속 버튼에 포커스를 둔다. Enter를 떼고 다시 누르면 다음 문제 또는 전투로 돌아간다. Enter 반복 입력으로 해설을 건너뛰거나 다음 문제에 중복 응답하지 않는다.
- 답안 버튼이 표시된 동안 방향키는 선택에 사용하고 전투 이동은 WASD로 할 수 있다. WASD 입력은 답안 탐색으로 초기화하지 않는다. 답안 버튼이 숨겨진 정답 구슬 방식과 답안 처리 후에는 기존 방향키 이동을 유지한다. 메뉴와 입력 필드의 키 조작은 가로채지 않는다.
- 전투·수학 타이머, 점수·에너지, 학습 저장·복습 알고리즘은 변경하지 않는다. Supabase와 보존 원본은 작업에 포함하지 않는다.

검증: 단위 테스트 91개, 기존 아이템 키보드 4개, 새로운 답안 키보드 16개(Edge/Chromium·WebKit, 1440×900·390×844, 탐험·팝업·전투 버튼·구슬). 네 방향, 순환, 정답과 오답 기록, Enter 반복 방지, 해설 포커스, 팝업 시간 정지, 답안 탐색 중 WASD 이동과 구슬 방식 방향키 이동을 확인한다. 테스트용 원거리 구슬로 순간 이동한 뒤 이동 검사를 할 때는 월드 중앙에서 검사하여 월드 경계와 입력 오류를 혼동하지 않도록 했다. 정적 빌드와 오프라인 실행도 검사한다.
