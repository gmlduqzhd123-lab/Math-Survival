# 새 월드 플레이 점검과 수정

2026-10-11. 새 맵에서 실제 키보드/터치 이동으로 보물방·비밀 포털·상인에 접근하고 자동 접촉을 검사했다. 먼 장소는 접근 직전 위치까지 테스트 준비로 이동시켰으며 전체 월드를 처음부터 걸어서 완주한 검사는 아니다.

## 수정한 문제

- 상인에게 접근하는 동안 유지한 이동 입력을 창이 열릴 때 해제한다. 모바일에서는 그 손가락을 떼며 발생한 클릭이 상인 창의 닫기/구매 버튼으로 전달되지 않도록, 창 안에서 시작된 포인터 클릭만 받는다. 키보드 Enter 선택은 그대로 지원한다.
- 3840×2160 화면에서 보이는 지형 수가 40개 캐시 한도를 넘어 매 프레임 다시 그리는 문제를 해결했다. 이전 코드를 같은 브라우저에 적용한 비교에서 정지 화면 재렌더마다 지형 캔버스 112개가 생성됐으나 수정 후 0개다.
- 화면 크기에 따라 지형 청크의 월드 범위를 300/600/1200으로 조절한다. 이미지 캔버스는 항상 300×300으로 유지해 메모리 상한을 지키고, 구역 경계 색을 정확히 나눠 그린다. 저사양 설정 변경 시 장식 캐시도 재생성한다.
- 청크 장식 일부가 범위를 벗어나 잘리던 좌표 계산을 바로잡았다.
- 이미 발견한 구역을 왕복할 때 발견 알림이 반복되던 동작을 줄였다. 현재 위치 표시는 계속 갱신된다.

## 검증 범위

- `node tests/world-playtest.cjs`: 1440×1000 PC, 390×844 휴대폰 세로, 844×390 휴대폰 가로. 키보드와 Chromium의 실제 터치 이벤트로 보물방 접근/상자 생성, 비밀 포털 접촉/원거리 이동, 상인 접촉/입력 해제/손가락 해제 후 창 유지/시간 정지/닫기/전투 재개, 구역 경계 이동 검사. 4K 정지 화면 캐시 재사용 검사.
- `npm test`: 95개 통과. 구역 발견 알림의 한 판 내 중복 방지 테스트 추가.
- `node tests/world-browser.cjs`, `node tests/mobile-gestures.cjs`: 기존 월드·보상·저장 원문 보존 및 모바일 조이스틱·대시·회전 검사 통과.
- `node tests/item-keyboard.cjs`: 성장 카드/상인 방향키·Enter/마우스 선택 통과.
- `npm run build`, `npm run test:build-browser`: 정적 Pages 경로와 오프라인 로딩 통과.
- `npm run test:movement`: PC와 휴대폰 이동 검사 통과. 개발 PC 브라우저에서 측정했으며 실제 휴대폰 발열/배터리/성능을 측정한 것은 아니다.

학습·성장 데이터 형식, 원본 게임 파일, Supabase 설정/DB는 변경하지 않았다.
