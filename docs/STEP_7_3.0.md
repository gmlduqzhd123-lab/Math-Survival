# STEP 7 — 최종 최적화와 정적 빌드

버전을 3.0.0으로 올리고 메인 화면 설명서·메타데이터를 갱신했다. 서비스 워커에 모든 모듈과 신규 SVG를 추가했다. 초기 오프라인 재접속 검사에서 사전 캐시 목록의 중복 URL 때문에 설치 캐시가 실패했다. 중복을 제거한 목록으로 캐시하도록 수정하고 빌드 경로·오프라인 재접속을 다시 검사해 통과했다.

추가 정리: 상자 ID를 집합으로 기억해 순서가 섞인 중복 보상을 막았다. 성문을 통과한 분열 적은 새 개체를 생성하지 않는다. 합체 궁극기는 표적이 있어 실제 공격했을 때만 에너지를 소비한다. 네 궁극기의 실제 공격과 무표적 에너지 보존 검사를 추가했다.

최종 검사 명령·결과·성능 수치는 [VERIFICATION_3.0.md](VERIFICATION_3.0.md)에 기록했다. 기존 테스트 명령을 유지했으며 신규 test:v3/test:stress/test:build-browser 명령을 추가했다. CI에도 신규 브라우저 기능 검사를 연결했다. 빌드 결과는 dist이며 원격 push·Actions 실행·Pages 배포는 수행하지 않았다.

실물 기기 장시간 실행, 음향 청취, 사용자 플레이테스트는 남아 있다. 새 콘텐츠 그래픽은 원본 SVG/Canvas 임시 그래픽이며 전용 다방향 애니메이션 시트·독립 음원·절차 생성 던전 지도는 후속 목록이다. 이것을 완성된 자산으로 표시하지 않는다.
