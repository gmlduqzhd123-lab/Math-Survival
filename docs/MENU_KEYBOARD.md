# 메인·일시정지 메뉴 키보드 조작 · 2026-10-11

- 기존 아이템·답안 방향키 탐색을 재사용하여 메인의 버튼·접이식 메뉴·링크와 일시정지 메뉴의 버튼·접이식 메뉴를 탐색한다. 선택 위치는 파란 테두리로 표시한다.
- 메인에서 포커스 없이 방향키를 누르면 게임 시작 버튼을 먼저 선택한다. 일시정지 메뉴는 기존처럼 계속하기 버튼에 포커스를 둔다. Enter는 기존 클릭 이벤트를 실행하고 반복 키 입력은 차단한다.
- 숨겨진 요소, 비활성 버튼, 닫힌 details 안의 자식은 탐색에서 제외한다. 닫힌 details 내부가 일부 브라우저에서 레이아웃 사각형을 유지하는 문제를 검사 중 발견해 조상 details의 열림 상태도 확인한다.
- 학년·난이도 선택창, 체크박스, 입력칸은 Tab과 Shift+Tab으로 이동하며 기존 방향키·Space 입력을 유지한다. QR·앱 설치 등 별도 창이 열리면 뒤쪽 메인 메뉴의 방향키 탐색을 중단한다.
- 기존 게임의 방향키 이동·답안 선택·아이템 선택·P/Escape 메뉴 전환·마우스 클릭을 보존한다. 학습·성장 기록과 원본 파일, Supabase는 변경하지 않는다.

검증: 단위 테스트 91개, 메뉴 키보드 4개(Edge/Chromium·WebKit, 1440×900·390×844), 기존 아이템 4개 및 답안 16개. 게임 시작, 네 방향, 접이식 메뉴 열기/닫기, Enter 반복, 학년 선택창 Tab 이동, QR 창 포커스, 소리 변경, 설정 체크박스, 타이머 정지, 계속하기·P/Escape·메인 복귀를 확인한다. 정적 빌드와 오프라인 실행도 검사한다. 화면 크기 검사는 데스크톱 브라우저 기준이다.
