# 제공 BGM 연결

사용자 제공 MP3를 메인 화면과 전투·결과 화면에 연결했다. 첫 신뢰된 클릭·터치·키 입력에서 Web Audio를 시작하며, 음소거를 저장한 사용자는 소리를 켜기 전까지 시작하지 않는다. 숨겨진 탭은 오디오 컨텍스트를 중단하고 이후 사용자 조작에서 재개한다.

음원은 한 번 디코딩해 버퍼 하나와 루프 소스 하나를 유지한다. 게임 재시작이나 메뉴 이동으로 다시 생성하지 않는다. MP3 원본은 유지하고, 재생 버퍼의 무음 가장자리를 정리한 뒤 끝의 2초를 시작과 선형으로 겹친다. 프레임 타이머 없이 오디오 시계로 반복한다. 디코딩 버퍼는 44.1kHz 기준 약 50MiB이며, 겹치기 위해 전체 버퍼를 추가 복제하지 않는다.

기존 전체·음악·효과음 음량 설정을 사용한다. 기본 음악 게인은 `0.12 × 0.6 = 0.072`로 효과음을 가리지 않도록 낮게 유지했다. 음소거 변경 직후 설정을 저장한다. 합성 멜로디 타이머는 제거하고 정답·대시 등 합성 효과음은 유지했다. 음원 로드 실패는 게임 시작을 막지 않으며 다음 조작에서 재시도한다. 정적 빌드와 서비스 워커에 음원을 포함했다.

검증: 단위 테스트 100개, 기존 게임 브라우저 회귀 검사, PC 1440px·모바일 390px에서 실제 MP3 디코딩과 음악 출력 신호, 사용자 조작 후 시작, 음소거, 음량·음소거 저장, 재시작 소스 재사용, 가속 반복 검사 통과. 빌드 경로와 오프라인 MP3 재생도 통과했다. Windows Playwright WebKit에는 Web Audio API가 없어 실제 재생은 검증하지 못했고, 오디오 없이 게임이 실행되는 경우를 확인했다. 실물 휴대폰 및 스피커 청취 검증은 포함하지 않는다.
