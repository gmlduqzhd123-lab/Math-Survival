# 2026-10-17 학생 사용성 개선

학생 사용성 점검에서 찾은 12가지 불편을 고쳤다.

| # | 불편 | 바뀐 점 |
| --- | --- | --- |
| 1 | 이동 중 오답 구슬에 스치기만 해도 답이 됨 | 구슬 위에 0.6초 머물러야 답이 된다. 머무는 동안 초록 원이 찬다(`ORB_HOLD_MS`). |
| 2 | 수학을 안 풀어도 성장 | 정답 하나가 현재 레벨 경험치의 절반을 준다. 오답 벌칙은 체력 2 → 10(체력 1 아래로는 내려가지 않음). |
| 3 | 누구 기록인지 모름 | 첫 화면에 선택 입력 ‘내 번호’(1~99, 이름 없음). 기록·파일 이름·결과 화면·교사 학급 집계에 번호가 들어간다. |
| 4 | 휴대폰에서 구슬이 조이스틱·대시 위에 놓임 | 엄지 영역과 지역 이름표를 피해 구슬을 놓는다. 지도 버튼 뒤는 계속 피한다. |
| 5 | 오답 알림이 바로 덮이고 글자가 겹침 | 정답·오답 알림은 2.8초 동안 다른 알림에 덮이지 않는다. 머리 위 ‘정답: N’을 더 크고 높게 표시한다. |
| 6 | 해설에 문제가 없음 | 해설 줄에 원래 문제와 내 답을 함께 보여 준다. |
| 7 | 저학년 읽기 부담 | 문제 옆 🔈 버튼으로 문제를 우리말로 읽어 준다(브라우저 음성 합성). 레벨업 카드의 진화 조건은 짧은 한 줄로 분리했다. |
| 8 | 터치 기기에 키보드 안내 노출 | 레벨업·상점·일시정지·문제 창의 키보드 안내를 터치 기기에서 숨긴다. |
| 9 | 결과 화면이 길고 어려운 말 | ‘다시 도전/처음 화면’을 점수 바로 아래로 옮기고 휴대폰에서 점수 칸을 2열로 배치했다. 학습 기록 문구를 아이 눈높이로 바꿨다. |
| 10 | 시작 화면이 산만함 | 경험치 구슬을 작게 그리고 ‘EXP’ 글자를 없앴다. 시작 아이템을 5개에서 3개로 줄였다. |
| 11 | 구슬이 지역 이름표를 가림 | 4번과 함께 처리. |
| 12 | 문제 내용 | 1학년 도형 문제는 ‘변’ 대신 ‘곧은 선’으로 묻는다. 답이 자연수인 분수 문제도 보기를 분수로 만든다(1.0333 제거). 최근 6문제와 같은 문제는 다시 내지 않는다. 문항 생성기 버전 5. |

문제 팝업 방식에서는 정답으로 레벨이 오르면 해설을 다 본 뒤 레벨업 카드가 열린다.

## 검증

- `npm test` 112개 통과(새 `tests/student-usability.test.js` 포함).
- 무작위 방향 이동 시험(휴대폰 화면, 6초마다 새 문제): 이전 버전은 90초 동안 19문제 모두 이동만으로 답이 됐고 14개가 오답이었다. 바뀐 버전은 같은 조건에서 0문제였다.
- CI의 Chromium 브라우저 검사 목록을 로컬에서 실행해 통과했다. `review-export.cjs`는 이 환경의 Chromium이 다운로드 파일 이름을 돌려주지 않아 원래 코드에서도 실패하므로 CI 결과로 확인한다. WebKit 검사도 CI에서 확인한다.
