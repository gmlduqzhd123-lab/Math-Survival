# 모바일 전투 화면·버튼 확대

모바일 터치 화면에서는 조작 줄을 전투 화면 안의 하단으로 옮겨 빈 공간을 전투 영역으로 사용한다. 조이스틱·대시는 세로 88px(기존 64px), 가로 72px(기존 48px)로 확대했다. 조이스틱 손잡이는 40px이며 중앙 빈 공간은 터치를 가로채지 않는다. PC 배치는 유지한다.

정답 구슬은 하단 버튼 영역과 미니맵 버튼을 피한다. 표시 공간에 맞춘 구슬 반지름을 생성·회전 시 동일하게 사용하고, 문제 표시로 화면 높이가 바뀐 직후 카메라와 구슬 위치를 다시 계산한다. 알림은 큰 버튼 위에 표시한다. 문제와 답안 버튼은 전투 영역 밖에 유지한다.

## 검증

- `node tests/mobile-size.cjs`: 320×568·390×844·844×390·768×1024에서 버튼 크기, 화면 넘침, 구슬 4개 유지, 조작·지도 버튼 뒤에 구슬이 가려지지 않는지 검사한다. CI에 추가했다.
- 이전 공개 버전과 같은 단원·화면 크기로 비교한 결과 전투 영역 높이는 320/390px 휴대폰에서 72px, 가로 휴대폰에서 58px, 768px 태블릿에서 76px 증가했다.
- `npm test`: 91개 통과. 간결한 플레이 Chromium 6개, 긴 문제·큰 글자·보스·답안·학습 백업 회귀 검사, 신뢰된 터치 길게 누르기·두 손가락 대시·취소·회전 검사도 실행했다.
- 빌드와 `/Math-Survival/` 하위 경로 오프라인 실행을 검사한다.
- 이전 ‘모든 영역 분리’ 검사는 모바일 조작 영역만 전투 영역 하단에 들어가는 새 배치로 갱신했다. 조작 영역이 전투 영역 안에 들어가는지와 문제·답안 영역을 가리지 않는지는 별도로 검사한다.

검사는 브라우저의 모바일 에뮬레이션이다. 보존용 원본, 학습·성장 저장 구조, Supabase 설정은 변경하지 않는다.
