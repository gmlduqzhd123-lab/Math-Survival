# 모바일 플레이 재검수 (2026-10-11)

## 발견한 표시 문제와 수정

- 320px 폭의 화면에서 HUD의 ‘경험치’ 단어가 중간에 줄바꿈됐다. 경험치 표시는 하나의 줄바꿈 단위로 묶어 단어와 숫자가 갈라지지 않도록 했다.
- 화면 하단 알림이 조이스틱·대시를 덮었으며 긴 문구는 말줄임 처리됐다. 같은 알림 DOM과 타이머를 재사용하면서 전투 영역 안으로 옮겼다. 문구는 줄바꿈하고, 문제·답안·터치 조작 영역과 겹치지 않도록 했다. 알림은 기존처럼 입력을 가로채지 않는다.

## 검사 범위

공개 사이트의 Chromium/Edge와 WebKit에서 320~1280px 폭의 휴대폰·태블릿 프로필을 검사했다. 게임 시작, 분수 문제와 큰 글자, 답안 터치·해설 시간 정지, 목표 종료, 실제 결과 JSON 다운로드, 새로고침 후 기록 보존, 조이스틱·대시·특수 스킬, 회전과 입력 해제, 보스·종료를 확인했다. 별도 타이포그래피 검사와 간결한 전투 UI 검사도 실행했다.

수정 후 `node tests/mobile-gestures.cjs`는 320×568·390×844·844×390에서 신뢰된 CDP 터치로 900ms 누르기, 두 손가락 이동/대시, 해제·취소, 문자 선택·컨텍스트 메뉴, 큰 글자·회전을 검사한다. 긴 알림의 실제 글자 경계, 문제·조작 버튼과의 겹침, 경험치 한 줄 표시도 확인한다. CI에 이 검사를 추가했다.

학습·성장 저장 구조, 문제 생성, 전투 규칙, 보존 원본 및 Supabase 설정은 변경하지 않았다. 화면과 입력은 데스크톱 브라우저의 모바일 에뮬레이션이며 실물 Android/iOS 기기 검수나 실제 오디오 재생 검증은 아니다.

## 배포 전 결과

- 공개 기존 버전: 모바일·태블릿 18/18, 타이포그래피 14/14, 간결한 플레이 12/12 통과. 기능 검사는 통과했으나 스크린샷에서 표시 문제를 발견했다.
- 긴 알림의 경계·버튼 겹침을 검사하는 새 테스트는 공개 기존 버전에서 실패하여 표시 문제를 재현했다.
- 수정한 소스와 정적 빌드: 모바일 제스처·긴 알림 검사 각각 3/3, 간결한 플레이 Chromium 6/6, 기본 단위 테스트 91/91, 빌드·오프라인 실행 통과.
