# STEP 6 — 교사용 기능

학년·영역·단원·수학 단계·자동 조절·문항 목표·0 또는 30~1800초 제한·전투 난이도·문제 표시 설정을 검증한 URL로 공유한다. 접속 시 설정만 적용하고 자동 시작하지 않는다. 실명은 수집하지 않는다.

학생 개별 JSON/CSV와 기존 리포트를 유지한다. 학급 합치기는 문항 원본이 있는 결과 JSON/전체 백업 JSON을 최대 50파일·각 10 MiB까지 읽는다. sessionId 중복을 제외하고 문항 수 기준 정확도, 유형별 오답·힌트·복습을 집계한다. 잘못된 파일은 제외 사유를 표시한다. 학급 CSV 다운로드와 메모리 비우기를 제공한다. 학생 학습 저장소에는 합친 자료를 쓰지 않는다. CSV 입력 합치기는 지원하지 않는다.

검증: 단위 82/82. 브라우저에서 공유 URL 재접속, 설정 적용, 실제 시간 제한 종료, 중복/잘못된 파일 처리, CSV 다운로드, 집계 비우기 통과. 기본 무제한 회귀 fixture는 0초를 명시하고, 사용자 지정 시간은 별도 검증한다. 실시간 모니터링·자동 동기화는 구현하지 않는다.
