# 3.0.1 후속 작업 — 2026-10-10

사용자가 남은 작업 및 검수 후 push·배포를 승인했다.

## 실제 구현

- 신규 캐릭터 7종: 4방향×3프레임 SVG 시트, 이동 방향·속도에 따른 프레임, 정지/효과 감소 대응. 기존 3종의 사용자 에셋과 Canvas 애니메이션은 유지.
- 몬스터 10종: 날개·뿔·활·버섯·등껍질·꽃·얼음·왕관 등 서로 다른 원본 그래픽과 3프레임 애니메이션. 체력 표시·엘리트 테두리·돌진 예고 보존.
- 월드 음악 6곡: 각각 다른 선율·베이스·템포·악기의 원본 WebAudio 작곡. 다른 게임 음원을 복제하지 않음. 게임 정지·탭 숨김 중 예약 억제.
- 수학 던전: 독립 1000×720 방, seed 기반 벽 배치, 안전한 진입 위치, 이동·대시의 분할 충돌 처리, 3문항마다 새로운 방·보상. 마지막 목표 완료 때는 다음 빈 방으로 넘어가지 않음.
- 상인: 회복20/보호막25/에너지25/패시브30 골드 상품 선택. 선택 중 전투 시계 정지, 구매/닫기 시 이전 정지 상태 복원, 메뉴 이동 시 정리.
- 성능: 미해제 수학 보호막을 가진 중간 보스가 장시간 계속 쌓이는 문제를 부하 검사로 발견. 동시 활성 중간 보스 2개 상한을 추가하고 재검증. 새 판에서 성장 HUD 갱신 시각도 초기화.

## 검증

단위86/86, 기존 브라우저30개, 신규6개 브라우저 시나리오 통과. 화면 글자14·설정6·이동2·화면 크기4 검사와 휴대폰/태블릿18개 프로필 통과. 기기 첫 검사17/18 중 WebKit 태블릿 한 프로필은 보스 HUD 고정150ms 대기에서 실패했다. 표시 상태를 기다리는 검사로 변경하고 해당 프로필1/1 재검증했다. verification-3.0.1/devices.json에 최초 실패와 재검증을 함께 보존했다. 새 브라우저 검사는 실제 3문항 응답에 따른 방 전환, 벽 겹침 해소, 상인 P키 정지 유지·구매·닫기, 픽셀 데이터로 애니메이션 프레임 차이, 중간 보스 상한, 런타임/네트워크 오류 부재를 확인한다.

이동 측정 중앙값16.7ms, p95 PC·휴대폰 크기 모두16.9ms. 약12초 HUD 변경23/27회. 30분 검사는 불사·경험치 억제의 가속 자동 부하이며 자연 플레이나 실물 휴대폰 발열 검사가 아니다. 정적 빌드의 /Math-Survival/ 하위 경로와 서비스 워커 오프라인 재접속을 재검증한다.

원본 파일 해시와 학습 엔진·숙련도 코드는 보존한다. 신규 게임 성장과 학습 기록은 독립이다. 수학 정답 검증·복습·보상 원장은 재사용했다.

## 이 환경에서 완료할 수 없는 확인

실물 Android/iPhone/iPad의 발열·배터리·30분 자연 플레이, 사람의 음원 청취와 학생·교사 플레이테스트는 장비와 참가자가 없어 실행하지 않았다. 자동 브라우저의 터치·회전·장시간 부하 결과로 대체 근거를 제공하지만 해당 실물 검증을 완료로 표시하지 않는다. 원본 벡터 그래픽·합성 음악은 실제 사용 가능하며, 추후 전문 일러스트/연주 녹음 교체는 선택 사항이다.

## 배포

최종 테스트가 통과한 커밋을 main에 fast-forward push하고 GitHub Pages Actions 및 공개 URL에서 버전·콘텐츠 로딩을 확인한다. 실제 배포 결과와 커밋은 최종 응답에서 보고한다. 배포는 학습 localStorage를 삭제하지 않는다.
