복습은 매 3번째 출제 기회에 선택된 단원의 기한이 된 문제를 확인합니다. 실패는 즉시 대기 상태, 복습 시도 후 다음 기한은 60초 뒤입니다. 수학 문제 공간이 유한한 단원에서 새 동형 후보를 얻지 못하면 같은 문제를 새 문항으로 카운트하지 않습니다. 도형 단원은 방향 문맥도 개념 식별에 포함하며 변의 개수는 방향에 따라 변하지 않습니다.

## 저장·복원·삭제 정책

- v1 키 `math-survival-2.records.v1`과 `.backup`은 이관 때 보존합니다. v2 키는 `math-survival-2.learning.v2`입니다.
- v2 JSON 전체가 손상된 경우 교체 전에 `.damaged-backup`으로 원본을 보존하고 격리 데이터에도 담습니다. 정상 행은 손상 행과 함께 버리지 않습니다.
- 과거 기록의 `responseMs`, `hintUsed` 등을 채워 넣지 않습니다. 알 수 없는 과거 종료 상태는 `legacy`로 구분합니다.
- 같은 sessionId 백업은 기존 기록을 우선하여 중복 저장하지 않습니다. 복습 성공 개념은 병합하므로 해소된 상태를 오래된 실패 백업으로 되돌리지 않습니다.
- 선택 삭제는 학습 기록을 삭제하고 숙련도/복습을 초기화합니다. 전체 삭제는 이관 원본·백업·손상 백업·격리 데이터도 제거합니다. 적용 전에 UI에서 확인합니다.
- 백업 복원은 파일 선택만으로 저장되지 않습니다. 미리보기의 새 기록/중복 수 확인 후 적용해야 합니다. 같은 브라우저 사용자의 기록 접근 가능성을 안내합니다.

## 제외·미검증 사항

- 단계 3: 과제 URL, 시각 학습 확장, 독립 복습 활동. 단계 4: 학습 보스, 도감, PWA. 이번 구현에 포함하지 않았습니다.
- 원격 GitHub Actions/Pages 실행 및 원격 게시를 하지 않았습니다. 로컬 빌드/검증이 원격 CI 통과를 뜻하지 않습니다.
- Android/iOS 실물 단말, iOS Safari, 실제 두 손 하드웨어 터치, 오디오 청취는 미검증입니다.
- 180초 자료는 설치된 Windows Edge의 headless 렌더링 측정입니다. 전체 스트레스를 유지하기 위해 HP를 보호하고 성장 카드를 자동 선택했습니다. 일반 플레이 생존 성공, 모바일 성능 또는 소리 재생 품질로 해석하지 않습니다. 게임 시계는 카드 선택 일시정지 때문에 wall-clock보다 짧을 수 있습니다.
- 저장 용량은 브라우저 quota에 의존합니다. 기록을 자동으로 잘라내지 않으며 저장 실패를 알리고 현재 결과를 내려받게 합니다. 서버 저장·기기 간 동기화는 없습니다.
