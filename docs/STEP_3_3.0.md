# STEP 3 — 수학·전투 통합

math-engine.js/mastery.js/storage.js를 유지하고 문항 인스턴스별 RewardLedger를 붙였다. 정답은 수학 에너지 12(+패시브)를 주고 전투 경험치와 분리한다. 학습 업적/수학 미션의 경험치도 분리했다. 오답의 체력 감소는 최대 2이며 오답만으로 사망하지 않는다. 탐험의 오답 피해 없음은 유지한다.

전투 계속 구슬 방식과 전투 정지 팝업 방식을 선택한다. 팝업에서는 고정 게임 시계·P·키 이동이 멈추고 답변 후 해설 확인을 누르면 전투가 재개된다. 힌트는 기존 학습 기록/난이도 제외 규칙을 사용한다. 보스 보호막은 정답으로 감소하며 활성 상태의 피해는 20%로 줄고 체력 1 아래로 내려가지 않는다. 기존 무기 피해는 동일 피해 훅을 통과한다.

검증: 76 단위 검사, 기존 30 플레이 회귀, 실제 팝업 시간 정지·힌트 기록·경험치 분리·에너지/보스 보호막·중복 응답·메뉴 해제 검사 통과. 최초 회귀에서 피해 훅 치환 오류와 학습 업적의 추가 경험치를 발견하여 수정하고 재실행했다. 기존 마지막 응답/사망 경합 테스트는 오답만으로 사망시키지 않고 별도 전투 사망 조건을 명시했다. 학습 저장 키 및 스키마는 변경하지 않았다.
