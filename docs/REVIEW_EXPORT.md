# 틀린 문제와 해설 저장

결과 화면의 단일 게임 JSON 저장 버튼을 제거했다. 저장 버튼은 `틀린 문제와 해설 저장`으로 바꾸고, 결과 화면의 오답 해설과 같은 `reviewProblems` 목록을 CSV로 내보낸다. 열은 문제, 내 답, 정답, 해설이며, 맞힌 문항과 게임 통계는 포함하지 않는다. 한글 호환을 위해 UTF-8 BOM을 넣고, 따옴표와 줄바꿈을 보존하며 수식 실행을 막는다.

틀린 문제가 없으면 버튼을 비활성화하고 안내한다. 다음 게임에서 오답이 생기면 다시 활성화한다. 기존 브라우저 학습 기록과 전체 백업·복원, 교사용 보고서 기능은 유지한다.

검증: 단위 테스트 98개 통과, 기존 브라우저 회귀 테스트 통과, PC 1440px·모바일 390px에서 전부 정답→재시도→오답 해설 다운로드 검증 통과. 브라우저 저장 차단 상태에서도 오답 해설 다운로드를 검증했다. 정적 빌드와 빌드 경로·오프라인 실행 검증 통과. 모바일 검증은 Playwright 에뮬레이션이다.
