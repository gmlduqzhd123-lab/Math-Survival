# 3.0.2 실제 입력 플레이와 밸런스 검수

검수일: 2026-10-10. 기준은 배포된 3.0.1이며 기존 엔진을 재사용했다.

## 검사 방식

브라우저의 실제 키보드 입력 및 Chromium의 신뢰된 터치 입력으로 플레이했다. 매 판 격리된 새 저장소와 기본 탐험가(체력 140)를 사용했다. 체력/경험치 증가, 무적 설정, 강제 레벨업, 게임 시간 건너뛰기를 하지 않았다. 적을 피하면서 보석을 수집하고 화면의 성장 카드를 클릭했다. QA 객체는 좌표·체력·선택지의 읽기에만 사용했다. 팝업 정답은 QA의 정답값으로 선택하므로 학생의 수학 수행력 검사가 아니다. 기본 짧은 플레이, 스킬·대시 사용 플레이, 수정 후 180초 제한 플레이를 구분해 JSON에 남겼다. 원래 정답 구슬을 찾아가는 휴대폰 터치 플레이도 별도로 진행했다.

공격 판정·상인·보스 경계 검사는 상태를 통제하는 별도 단위/브라우저 검사다. 30분 성능 검사는 무적·저사양 상태로 시간 가속한 시뮬레이션이며 실제 30분 생존 기록이 아니다. Windows 브라우저 에뮬레이션이며 실물 휴대폰·학생 대상 재미 검증이나 오디오 청취 인증을 의미하지 않는다.

## 확인한 문제와 수정

1. 시작 무기가 성장하지 않는 문제: 기본 검사에서 주판/별자리/주사위가 여러 성장 카드 선택 후에도 Lv.1에 머물렀다. 편향된 sort 무작위 섞기를 Fisher–Yates로 바꾸고 보유 무기 성장 카드를 적어도 한 장 제공한다. 나머지 두 장은 새 무기·패시브·기존 강화 선택이다.
2. 쉬움 보스의 접촉 피해가 보통과 같았다. 보스/중간 보스 체력·속도·접촉 피해 모두 난이도로 조절한다. 쉬움은 체력 80%, 이동 85%, 피해 65%; 보통은 기존 값; 어려움은 각각 120%, 115%, 130%다. 위험 영역 피해의 기존 난이도 차이는 유지한다.
3. 45초 첫 보스와 90초 중간 보스가 초반에 겹쳤다. 일반 생존의 첫 보스를 쉬움 180초·보통 120초·어려움 90초로 변경했다. 이후 보스 간격은 150/120/100초, 중간 보스 간격은 240/180/120초다. 기존 보스 챌린지의 즉시 등장·3연전과 무제한 생존은 보존한다.
4. 별자리 무기는 공격 순간의 세 위치에서만 판정하던 것을 회전 중 실제 위치에서 타격하도록 수정했다. 같은 회전 주기의 같은 별은 같은 적을 중복 타격하지 않는다. 적 풀 재사용 UID도 구분한다.
5. 무한 자의 레벨 상승으로 늘어난 광선 수와 관통 수가 판정에 반영되지 않았다. 부채형 다중 광선과 관통 상한을 적용하고 같은 발사에서 같은 적에게 중복 피해를 주지 않는다.
6. 체력/보호막/수학 에너지가 가득 찼거나 힘의 연필이 최대 단계일 때 상인이 효과 없는 구매를 받았다. 버튼과 구매 함수 양쪽에서 차단하고 골드를 보존한다.

## 최종 기본 능력치 플레이 관측

아래는 스킬·대시를 사용하는 자동 조작 1회씩의 관측이다. 난수와 선택 조합이 다르므로 수정 전후 생존 시간을 통계적 개선율로 해석하지 않는다. 보통 휴대폰 판의 사망도 숨기지 않는다. 팝업/성장 카드 동안 시간이 멈춰 벽시계 시간과 전투 시간이 다르다.

모든 판에서 입력 해제 후 조이스틱 고착과 페이지 실행 오류는 없었다. 정답 구슬 터치 판은 전투 124.1초, 체력 80, 처치 175, 레벨 8, 정답 3회로 정상 진행 중 검사 제한에서 종료했다(play-orbs.json). 보스 경고 회피·진화 조합 선택까지 완벽하게 수행하는 사람의 장기 플레이를 대신하지는 않는다.
