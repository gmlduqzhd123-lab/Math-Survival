# 모바일 시작 실패 보강

2026-10-10. 사용자 화면에서는 설정 UI가 생성되지 않았고 조이스틱이 메인 화면에 겹쳐 있었다. 기기 로그가 없으므로 해당 기기의 정확한 원인은 확정하지 않았다.

기존 모듈 진입점에서 structuredClone을 제거하면 설정 생성 전에 초기화가 중단되는 것을 재현했다. 게임의 JSON 기록용 복제, Array.at, UUID 생성의 구형 Android 호환 처리를 모듈 실행 전에 추가했다. 초기화 전 시작 버튼은 비활성화하고, 파일 다운로드·초기화 실패는 안내와 다시 불러오기 버튼으로 표시한다. 복구는 해당 앱의 서비스 워커 업데이트와 페이지 재로딩만 수행하며 localStorage나 다른 앱의 캐시를 지우지 않는다. 초기 화면 조작 UI 겹침도 막았다.

정적 빌드는 런타임 내용의 해시를 진입 스크립트·모든 모듈 의존성·CSS·오프라인 사전 캐시 주소에 붙인다. 줄바꿈을 정규화해 Windows/CI의 해시를 통일한다. 서비스 워커는 해당 앱 경로와 현재 버전 캐시만 사용하고 설치 파일을 모두 받은 후 활성화한다.

검증: 단위 91개 통과, 기존 학습/전투 브라우저 회귀 통과, Chromium UI 6개 화면 통과, 정적 경로와 오프라인 빌드 검사 통과. Edge·WebKit에서 기존 실패 재현, 현대 브라우저 시작, 구형 API 누락 상태의 시작과 기록 보존, 진입 파일 실패와 재시도, 모듈 실패 후 복구 및 다른 앱 캐시가 있는 오프라인 실행 등 10개 시나리오가 통과했다. 실패 재현은 브라우저 API를 제거한 자동 검사이며 실물 사용자 기기 검증은 아니다.

원본 index, 학습 키 math-survival-2.learning.v2, 성장 키 math-survival-3.progress.v1의 형식은 유지한다. Supabase는 배포 범위에서 제외한다.
