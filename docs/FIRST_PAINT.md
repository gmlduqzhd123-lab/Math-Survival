# 첫 접속 화면 전환 수정

원인: 정적 HTML의 기존 시작 메뉴가 먼저 표시된 뒤 비동기 모듈과 학습 데이터 로딩이 끝나면 간결한 메뉴로 재구성됐다. 동적으로 만든 로딩 화면도 모듈 로딩 전에는 존재하지 않았다.

수정: 초기 HTML에 불투명한 로딩 화면과 최소 스타일을 넣었다. 메뉴 재구성 전에는 게임 영역을 숨기되 레이아웃 계산은 유지한다. 초기화 후 글꼴 준비를 기다리고(최대 1.5초), 완성된 메뉴를 표시한다. 진입 스크립트 실패 시에도 로딩 화면에 재시도 안내가 보인다. 저장 데이터는 변경하지 않는다.

검증: 모듈 응답을 지연시킨 390px·1440px 첫 화면 검사, 게임 시작, 시작 실패·구형 API·재시도 5개 시나리오, 단위 테스트 98개, 정적 빌드 경로와 오프라인 실행 검사 통과. 모바일은 브라우저 에뮬레이션으로 검증했다.
