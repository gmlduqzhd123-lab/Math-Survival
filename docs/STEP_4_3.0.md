# STEP 4 — 콘텐츠 확장

기존 3캐릭터·3월드·3보스를 유지하고 총 10캐릭터/8펫/6월드/6보스로 확장했다. 신규 캐릭터는 시작 무기·별도 능력치·7 고유 스킬을 제공한다. 원본 요정 공격을 재사용하며 추가 펫의 공격·회복·보석 수집·보호막·감속·연쇄·1회 부활을 연결했다. 원본과 신규 보스 모두 체력 2/3·1/3에서 3페이즈로 전환한다. 신규 보스별 예고 영역·중간 보스·골드 보상·보물방/상인/강화 제단/비밀 포털 이벤트를 구현했다. 신규 캐릭터용 직접 작성 SVG 원본 7개와 Canvas 재사용 캐시를 추가했다. 다른 게임의 에셋을 사용하지 않았다.

검증: 77 단위 검사, 기존 30회귀, 실제 UI에서 신규 캐릭터 7 스킬·8 펫 효과·신규 3보스 페이즈/예고·상인/제단/포털 판정 검사 통과. 펫 검사에서 일시정지 상태로 공격을 기대하던 조건을 수정하고 실제 실행 상태로 재검증했다. 해금과 영구 저장은 다음 STEP 5에서 연결한다. 원격 쓰기 없음.
