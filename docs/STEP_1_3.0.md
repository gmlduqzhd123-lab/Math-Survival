# STEP 1 — 핵심 전투

10종 몬스터의 추격/돌진(850ms 예고)/원거리/분열/소환/탱커/회복 AI를 기존 enemy 업데이트에 연결했다. 30초 웨이브, 90~220 적 예산, 100 적 탄환 풀, 128px 공간 그리드, 화면 밖 100ms AI 처리, 보석 값 보존 병합, 투사체/이펙트 상한과 프레임 기반 자동 저사양 판정을 구현했다. 기존 보스·기본 공격·학습·펫·포털 경로를 유지한다.

검증: 71 단위 검사, 기존 플레이 30회귀 통과. 12초 실제 키 이동 p95: PC 16.8ms / 휴대폰 뷰포트 16.9ms. 이는 장시간 30분 전투 및 실제 기기 성능 검증을 대신하지 않는다. 풀과 그리드·병합 값 보존·10 AI 상태·웨이브·자동 최적화 검사를 추가했다. 다음 단계에서 무기와 보스 보호막의 피해 훅 및 별도 장시간 검증을 추가한다.
