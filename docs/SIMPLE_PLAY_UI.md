# 플레이 화면 단순화

2026-10-10. 사용자 승인에 따라 GitHub Pages 배포를 준비했다. 최신 main의 앱 설치·QR 기능을 보존하고 화면 개선만 반영했다. Supabase 연동 소스·SQL·설정은 배포 범위에서 제외했다.

## 플레이 동선

- 상단: 체력 막대, 레벨·경험치 막대, 작은 수학 에너지 표시, 메뉴 버튼.
- 문제와 답안: 문제가 있을 때 현재 문제를 표시한다. 전투는 정답 구슬을 기본으로 사용하고 답안 버튼은 메뉴에서 선택한다. 탐험은 기존 답안·해설·다음 문제 버튼을 유지한다. 팝업은 별도 정지 화면의 답안을 사용해 중복 답안 영역을 숨긴다.
- 조작: 이동·대시를 유지한다. 특수 스킬은 가까운 적이 있을 때 기존 스킬 함수와 쿨다운을 재사용해 자동 실행한다. 메뉴에서 직접 사용으로 바꾸면 버튼·E 키를 사용할 수 있다.
- 메뉴: P, Escape 또는 ☰로 전투와 시간 정지. 계속하기 또는 Escape로 복귀. 소리·화면 설정·게임 설명·미션·무기·효과·점수·시간·웨이브·메인 화면·종료를 모았다. 브라우저 기본 dialog를 사용해 키보드 초점이 메뉴 밖으로 벗어나지 않는다.
- 미니맵: 작은 지도 버튼으로 펼치고 접는다. 지도 버튼은 화면 중앙 상단에 놓아 모서리 답안 구슬의 숫자를 가리지 않는다.
- 일반 아이템: 130 게임 좌표 이내에서 가장 가까운 하나만 이름을 표시한다. 보스와 맵 이벤트의 설명은 유지한다.

## 보존과 수정 사항

`math-survival-2.learning.v2`, `math-survival-3.progress.v1`의 키·구조는 변경하지 않았다. 새 표시 설정만 `math-survival.ui.v1`에 저장한다. 기존 설정의 애니메이션·저사양·글자 크기 변경은 기존 이벤트를 통해 적용한다.

레벨 선택·문제 팝업·상인·탐험 해설 중에는 일반 메뉴 정지로 상태를 덮어쓰지 않는다. 메뉴 이동 시 응답이 없는 판에서도 dialog를 닫도록 수정했다. 문제 생성이 완료된 시점에 표시 영역을 동기화해 탐험의 다음 답안이 늦게 보이는 문제를 수정했다.

서비스 워커에 새 JS/CSS를 포함하고 앱 전용 캐시 버전을 올렸다. 다른 앱의 저장소와 캐시를 변경하지 않는다. 보존용 `original/index.html`은 수정하지 않았고 마이그레이션 추출 스크립트도 실행하지 않았다.

## 검증 범위

- 기존 단위 테스트: 91/91 통과.
- 새 브라우저 검사: Chromium(Windows Edge)·WebKit, 각 320×568 / 390×844 / 844×390 / 768×1024 / 1024×768 / 1920×1080. 기본 HUD·답안 접기·설정 전환·메뉴 정지/재개·Escape·대시·탐험·보스·팝업·기록 저장/새로고침을 검사한다. Chromium은 신뢰된 터치 드래그/취소도 검사한다.
- 기존 화면·설정 검사: 휴대폰·태블릿·PC와 기존 3개 모드의 무제한 시간·문제 간격·탐험 해설을 확인한다.
- 기존 회귀 검사: 학습 기록·복원·내보내기·무기·보스·맵 이벤트·교사용 과제 검사를 통과했다. 설정 6개, 글자 14개, 스프라이트 8개 화면 검사 및 이동 성능 검사를 통과했다.
- 정적 빌드: `/Math-Survival/` 경로에서 터치·팝업·대시·오프라인 모듈 로딩 통과.

자동 검사와 데스크톱 브라우저의 모바일 에뮬레이션이다. 실물 Android/iOS 기기와 학생 대상 사용성은 검증하지 않았다. 배포 성공은 별도로 Actions 및 공개 페이지에서 확인한다. `test-results/simple-play/report.json`에 실행 결과와 화면 크기를 기록한다.

빌드는 dist를 새로 생성하여 이전 브랜치의 클라우드 파일이 섞이지 않도록 한다. 빌드 산출물에 src/cloud 및 src/ranking이 없음을 확인했다.
