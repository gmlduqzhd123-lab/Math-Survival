# 제공 이미지 적용

`math-survival-sprites.zip`에는 12종 그림의 256px/512px 버전이 각각 들어 있었다. 실제 서로 다른 그림은 12종이다. ZIP의 256px 투명 PNG를 픽셀 변경 없이 `src/assets/sprites/`에 보관하고 사용한다. 파일·ZIP의 SHA-256과 규격은 `supplied-sprites.json`에 기록했다. 512px 원본은 사용자 제공 ZIP에 남아 있다.

| 제공 그림 | 게임에서의 역할 |
|---|---|
| 회복 하트 | 회복 아이템, 회복력 성장 카드 |
| 무적 보호막 | 보호막 아이템, 수호자 장비, 분수 방패 무기·회전 방패 효과 |
| 수학 자석 | 끌어당김 아이템 |
| 수학 부메랑 | 돌아오는 부메랑 투사체, 해당 시작 무기·성장 카드 |
| 연필 검 | 탐험가 장비, 무지개연필 강화 아이템, 떨어지는 연필 투사체·성장 카드 |
| 지식의 지팡이 | 마법사 장비, 숫자 폭풍·연산 번개 무기 미리보기, 마법구 성장 카드 |
| 수학 폭탄 | 연산폭탄 아이템 |
| 속도 부츠 | 번개신발 아이템 |
| 지식의 책 | XP 그림에 맞춰 경험치책 아이템 |
| 시간 정지 시계 | 시간얼음·집중시계 아이템 |
| 보물 상자 | 랜덤 보상 아이템 |
| 마법 깃털펜 | 순간이동깃털 아이템 |

캐릭터 본체·몬스터·배경의 별도 그림은 제공되지 않았다. 기존 캐릭터 본체에 캐릭터별 장비를 연결했다. 대응 그림이 없는 별사탕·힌트 노트·지우개·클로버·보석 등은 기존 표시를 유지한다. 무기·아이템의 효과, 충돌 범위, 저장된 설정의 키와 학습 기록 구조는 변경하지 않는다.

## 렌더링과 실패 처리

- 게임 시작을 이미지 다운로드로 막지 않는다. 12종은 한 번만 다운로드·decode하고, 128px Canvas 캐시를 프레임마다 재사용한다. 약 0.75MiB의 렌더용 픽셀 버퍼이며 리사이즈·이동 중 새 이미지를 만들지 않는다.
- 메뉴는 256px 원본을 사용하고 좁은 화면에서 미리보기 카드가 한 열로 배치된다. 이름과 효과 설명은 텍스트로 남겨 둔다.
- 미리보기는 캐릭터·시작 무기 선택과 함께 변경된다. 아이템 안내에는 11개 연결된 아이템을 그림으로 표시한다.
- 이미지가 로딩되지 않으면 게임 Canvas는 기존 이모지·도형으로 표시한다. 서비스 워커에 새 스타일·모듈·PNG를 등록해 오프라인 사용 시에도 캐시한다.

## 검증

`npm run test:sprites`: Chromium/WebKit에서 320×568, 390×844, 768×1024, 1920×1080 조건을 검사한다. 12종 로딩, 캐릭터·무기 미리보기, Canvas의 실제 이미지 사용, 투사체·장비·방패 표시, 성장 카드 선택과 이미지 전체 로딩 실패 시 플레이를 검증한다. 단위 검사 49개, 브라우저 회귀 검사 30개, 설정 검사 6개, 글자 잘림 검사 14개도 통과했다. 이는 자동 브라우저 검사이며 실제 모바일 하드웨어 검사와 구분한다.

스크린샷·검사 결과는 `test-results/sprites/`, 이동 측정 결과는 `test-results/movement/sprites-local.json`에 저장된다.

이미지 적용 후 12초 연속 이동 측정에서 데스크톱과 휴대폰 크기 모두 프레임 간격 중앙값 16.7ms, p95 16.9ms였다. 데이터는 `sprite-movement-benchmark.json`에 기록했다. 실제 기기의 FPS를 보장하는 수치는 아니다.
