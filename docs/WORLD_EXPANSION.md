# 연결된 대규모 월드 구현·검증

2026-10-11. 사용자 승인 범위: 넓은 연속 월드, 거대한 랜드마크, 비밀 장소를 결합하고 검증 후 GitHub Pages에 배포.

## 실제 구현

- 기존 6개 월드 각각 7200×5400, 3×3 구역과 12개 연결 도로. 이전 월드 면적 대비 약 5.2~7.3배.
- 총 54개 이름 있는 구역. 테마별 바닥색과 세계수·유적·탑·수정·야영지·성문 원본 벡터 그래픽.
- 월드마다 9개 고정 장소. 야외 보물방, 골드로 구매하는 상인, 에너지를 소비하는 제단, 먼 숨은 보물터로 이동하는 비밀 포털.
- 고정 장소 보상은 한 판에 한 번. 새 게임에서 초기화하며 기존 45초 주기 이벤트는 유지.
- 구역 발견 알림과 현재 위치 표시. 지도에는 발견한 구역의 색과 남은 장소를 표시.
- 랜드마크는 통과 가능한 배경으로 구현. 새로운 벽 충돌이나 실내 전환은 포함하지 않음. 수학 던전의 작은 방·벽 충돌은 기존대로 유지.
- 화면 범위만 지형을 생성/렌더링. 300px 지형 청크 최대 40개, 랜드마크 최대 4개 캐시. 저사양 설정에서는 청크 장식을 절반 이하로 감소.

## 검증

- `npm test`: 94개 통과. 6개 월드 연결성·좌표 범위·고정 배치·캐시 범위·발견 초기화·던전 분리 검증 추가.
- `node tests/world-browser.cjs`: 1440×1000 PC, 390×844 휴대폰, 820×1180 태블릿 화면에서 9개 구역 렌더링 및 4종 이벤트 검증. 같은 보물 중복 지급 차단, 실제 상인 구매·제단 강화·원거리 포털 이동, 6개 월드 시작과 던전 제외, 기존 저장 원문 유지 확인.
- `npm run test:browser`: 기존 모드·전투·포털·학습·오답 복습·저장 복원·다중 터치·6개 해상도 검사 통과.
- `npm run test:v3`: 무기·AI·수학 팝업·보스·성장·교사 기능·던전·상인·게임 모드 회귀 검사 통과.
- `node tests/mobile-gestures.cjs`, `node tests/mobile-size.cjs`: 실제 브라우저 터치 이벤트로 조이스틱/대시/해제/취소 및 버튼 크기 확인.
