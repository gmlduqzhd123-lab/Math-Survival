# 선명한 글꼴과 아기자기한 화면 · 2026-10-11

## 변경

- 본문·선택창·버튼·문제·Canvas 글자는 Pretendard Variable 1.3.9로 교체했다. 실제 500~900 굵기를 사용하며 합성 굵기와 글자 그림자를 사용하지 않는다. 기존 Jua는 크게 표시되는 메인 제목에만 사용한다.
- 크림 바탕, 민트 시작 버튼, 민트·살구·라벤더 메뉴 카드, 둥근 테두리와 짧은 그림자로 화면을 정리했다. 본문 16~18px, 선택창 17px, 시작 버튼 25px, 답안 버튼 18px를 기준으로 한다. 보조 상태와 저작권은 공간에 맞춰 12~15px를 사용한다.
- 학년 선택 → 게임 시작의 간결한 진입, 접힌 설정과 기록 메뉴, 기존 모바일 조이스틱·대시 크기와 게임 레이아웃을 유지한다.
- 구슬의 숫자도 새 글꼴 650 굵기로 측정하고 그리므로 줄어든 글자 폭과 실제 표시 폭이 일치한다.
- 글꼴은 게임과 함께 제공하고 서비스 워커에 포함한다. 런타임에 외부 글꼴 CDN을 요청하지 않는다. 원본 글꼴과 SIL OFL 라이선스를 `src/fonts`에 보관했다. 공식 출처: https://github.com/orioncactus/pretendard/tree/v1.3.9

## 검증

- 단위 테스트 91개 통과.
- 글꼴 검사: Chromium/Edge와 WebKit, 320·360·390·430·768·1024·1920px의 14개 조합. 모든 학년·단원의 선택값과 긴 문구 줄바꿈, 가로/세로 잘림, 탐험 정답·해설을 검사했다. 주요 본문·선택창·시작 버튼 대비는 4.5:1 이상이며 글꼴 로드·실제 굵기·그림자 없음도 검사한다.
- 간결한 메인 검사 8개: 시작 버튼 첫 화면 표시, 학년 선택, 설정 저장·복원과 시작.
- 플레이 화면 12개: 두 브라우저 엔진의 휴대폰·가로 화면·태블릿·PC에서 이동, 대시, 답안·해설, 일시정지, 모드 전환, 기록 보존과 그래프 영역 표시를 확인했다.
- 모바일 화면 검사 4개 및 실제 브라우저 터치 이벤트 검사 3개: 88px/72px 조작 버튼, 회전·취소·동시 대시·장시간 누르기, 구슬과 조작부 겹침 방지.
- 빌드 경로와 오프라인 재실행에서 자체 제공 한글 글꼴 로드를 검사한다. 시작 복구 10개 시나리오 통과.
- 플레이 화면 검사의 짧은 이동 구간에서 무작위 아이템/구슬 수집으로 답안이나 이벤트 창이 먼저 열릴 수 있어, 해당 입력 검사 장면만 분리했다. 실제 정답·해설·모드·기록 검사는 그대로 수행한다.

검사는 데스크톱 브라우저의 화면 크기·터치 에뮬레이션이다. 실물 휴대폰의 화면 패널과 운영체제 글꼴 래스터라이저까지 동일함을 보장하지 않는다. 학습·성장 저장 코드는 변경하지 않았으며, `original/index.html` SHA256은 `3B1F33DE3983D5B4ED789A8AB1DA1FFF62E07B46AA9F1B5B581B592B639D0AD9`로 유지한다. Supabase 작업은 제외한다.
