# 모바일 당겨서 새로고침 방지와 전투 템포

2026-10-11. 사용자가 문제 상황을 ‘화면을 아래로 밀다가 새로고침됨’으로 확인했다.

## 수정

- 루트의 세로 overscroll을 막고 게임 필드에는 touch-action:none을 적용해 브라우저의 당겨서 새로고침을 방지한다.
- 게임 중 HUD 등에서 발생하는 touchmove도 취소한다. 스크롤 가능한 메뉴/설명/학습 영역은 해당 방향으로 스크롤할 공간이 있을 때 허용하고, 경계에서 루트로 전파되는 스와이프는 차단한다. 범위 슬라이더와 텍스트 영역의 기본 조작은 유지한다.
- 전투 첫 웨이브에 쉬움 1마리, 보통/어려움 2마리를 바로 배치한다. 일반 몬스터 등장 간격은 초반 1055ms에서 930ms로 약 12% 감소한다. 후반 최소 간격 180ms와 개체 제한은 유지한다.
- 출현 거리는 화면의 짧은 변에 맞춰 조정한다. 휴대폰에서 520~760 대신 330~490 게임 좌표 거리로 등장해 접근 대기 시간을 줄인다. 몬스터 이동 속도는 6% 증가한다.
- 몬스터 체력·피해량, 보스 등장 시각·능력치, 수학 난이도와 학습/성장 저장 구조는 변경하지 않는다. 수학 탐험에는 몬스터를 추가하지 않는다.

## 검증

- `node tests/mobile-refresh.cjs`: 320×568, 390×844, 844×390 Chromium 터치 환경. HUD를 아래로 드래그하는 실제 터치 이벤트가 취소되고 페이지 이동 없이 게임이 유지됨, 메뉴 안의 위쪽 드래그는 실제 스크롤됨을 확인. 브라우저의 overscroll/touch-action 설정도 확인한다. 실제 휴대폰에서 브라우저 UI 새로고침 애니메이션을 검사한 것은 아니다.
- `node tests/mobile-gestures.cjs`, `node tests/v3-balance-browser.cjs`: 조이스틱·두 손 대시·해제·회전·보스 난이도 검사 통과.
- `npm test`: 등장 간격/거리/체력 유지 검증 추가, 총 96개 테스트 통과.
- `npm run test:stress`, `npm run test:movement`: 전투 개체 제한과 이동 성능 확인.
- `npm run build`, `npm run test:build-browser`, `node tests/world-playtest.cjs`: 정적 경로·오프라인 로딩·보물방/포털/상인 접촉 확인.

원본 게임 파일과 Supabase 소스/설정/DB를 변경하지 않는다.
